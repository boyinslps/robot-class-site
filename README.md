# 機器人校隊 第 1 堂 課堂網站

給學生看的靜態網站，用來上課投影：自我介紹、分隊、上課規則、比賽目標、分類積木與收納。

## 怎麼用

- 直接用瀏覽器開 `index.html` 即可，不需要網路伺服器（YouTube 影片和官網連結要有網路）。
- 鍵盤 `→` `←` 換章節；「今日流程」頁有計時器。
- 「比賽目標」頁是剪報模式：學生只看不操作，影片進頁面自動靜音循環播放（沒有網路就是黑畫面）。
- 「分隊」頁的名單只留在瀏覽器記憶體，不會儲存，也不會上傳。

## 放到網路上

整個資料夾都是靜態檔案，可以直接放到 GitHub Pages 或學校的網頁空間。

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 所有章節 |
| `style.css` | 樣式（投影用大字，支援深色模式與手機） |
| `app.js` | 章節導覽、計時器、分隊抽籤 |

## 內容來源

- 比賽規則：AERC 2026 第 38 屆 C01 機器人循跡挑戰規則（2026.08.31 版）。2027 年規則公布後要更新「四張比賽地圖」的表格。
- 影片：老師提供的兩支 YouTube Shorts（n6REThQOXAg、Wc96_zs8EsI）。
